# [Enhance] Heading khái niệm trong Điểm chính ghi Khái niệm

1. **Lịch sử thay đổi**

|             |                |                       |            |
| ----------- | -------------- | --------------------- | ---------- |
| **Version** | **Created by** | **Nội dung thay đổi** | **Ngày**   |
| v1.0        | BA Agent       | Tạo mới từ feedback   | 15.06.2026 |

2. **User Story**

Là một **Content Writer**, Tôi muốn **heading khái niệm trong block "Những điểm chính" ghi theo format "Khái niệm:..." thay vì "X là gì?"**, Để **block tóm tắt gọn gàng và nhất quán với chuẩn format**.

3. **Mô tả vấn đề**

Trong block "Những điểm chính" (Key Takeaways), heading khái niệm đang ghi theo dạng "X là gì?" giống heading trong bài viết. Theo feedback, format đúng phải là "Khái niệm:..." để phù hợp với tính chất tóm tắt của block.

4. **Yêu cầu giải pháp**

Cập nhật prompt/template cho block "Những điểm chính": heading về khái niệm không để tên heading là "X là gì?" mà ghi "Khái niệm: ..." theo format chuẩn.
