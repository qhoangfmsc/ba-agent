# [Feature] Format chuyển văn bản bình thường

1. **Lịch sử thay đổi**

|             |                |                       |            |
| ----------- | -------------- | --------------------- | ---------- |
| **Version** | **Created by** | **Nội dung thay đổi** | **Ngày**   |
| v1.0        | BA Agent       | Tạo mới từ feedback   | 15.06.2026 |

2. **User Story**

Là một **Content Writer**, Tôi muốn **có tùy chọn format chuyển nội dung thành văn bản bình thường (paragraph)**, Để **bài viết có đầy đủ các kiểu format như trên WordPress**.

3. **Mô tả vấn đề**

Hiện tại editor chỉ hỗ trợ format heading mà chưa có phần format chuyển thành văn bản bình thường (paragraph). Trên WordPress có đầy đủ tùy chọn format cho cả heading lẫn paragraph, nhưng tool hiện tại thiếu tính năng này, khiến người dùng không thể điều chỉnh format linh hoạt.

4. **Yêu cầu giải pháp**

Bổ sung tùy chọn "Paragraph" / "Văn bản bình thường" vào dropdown format của editor, tương tự như WordPress. Khi chọn, nội dung sẽ được chuyển về dạng paragraph bình thường, bỏ format heading nếu đang có.

5. **Acceptance Criteria**

|           |                      |
| --------- | -------------------- |
| **AC ID** | **Kết quả mong đợi** |
| AC-01     | Editor có tùy chọn format "Văn bản bình thường" / "Paragraph" trong dropdown format |
| AC-02     | Khi chọn, nội dung heading được chuyển thành paragraph bình thường |
