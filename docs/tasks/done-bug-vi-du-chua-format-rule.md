# [Bug] Ví dụ chưa format theo rule

1. **Lịch sử thay đổi**

|             |                |                       |            |
| ----------- | -------------- | --------------------- | ---------- |
| **Version** | **Created by** | **Nội dung thay đổi** | **Ngày**   |
| v1.0        | BA Agent       | Tạo mới từ feedback   | 15.06.2026 |

2. **User Story**

Là một **Content Writer**, Tôi muốn **phần ví dụ trong bài viết được format đúng theo rule**, Để **bài viết đồng nhất về format và chuyên nghiệp**.

3. **Mô tả vấn đề**

Phần ví dụ trong bài viết chưa được format theo rule viết content đã quy định. Ví dụ cần có format riêng (có thể là block, box, hoặc style khác biệt) để phân biệt với nội dung chính, nhưng hiện tại đang viết như text bình thường.

4. **Yêu cầu giải pháp**

Cập nhật prompt viết content: khi viết phần ví dụ, áp dụng đúng format theo rule (box, highlight, hoặc format đặc biệt). Đảm bảo AI nhận diện đúng đoạn nào là ví dụ để áp dụng format.

5. **Acceptance Criteria**

|           |                      |
| --------- | -------------------- |
| **AC ID** | **Kết quả mong đợi** |
| AC-01     | Phần ví dụ trong bài viết được format đúng theo rule (box/highlight) |
| AC-02     | Format ví dụ đồng nhất giữa các bài viết |
