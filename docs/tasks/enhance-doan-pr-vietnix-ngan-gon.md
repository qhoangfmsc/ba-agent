# [Enhance] Đoạn PR Vietnix viết ngắn gọn đi link danh mục

1. **Lịch sử thay đổi**

|             |                |                       |            |
| ----------- | -------------- | --------------------- | ---------- |
| **Version** | **Created by** | **Nội dung thay đổi** | **Ngày**   |
| v1.0        | BA Agent       | Tạo mới từ feedback   | 15.06.2026 |

2. **User Story**

Là một **Content Writer**, Tôi muốn **đoạn PR Vietnix được viết ngắn gọn 4-5 dòng và đi link về trang danh mục dịch vụ**, Để **phần PR tự nhiên, không quá dài, và link về đúng landing page**.

3. **Mô tả vấn đề**

Đoạn PR Vietnix hiện tại viết quá dài và chưa đi link đúng. Theo feedback, đoạn PR chung cần viết ngắn gọn 4-5 dòng, PR tổng quan cho dịch vụ Vietnix: phía trên chuyển đổi về dịch vụ cụ thể (ví dụ hosting), bên dưới giới thiệu chung và đi link về trang danh mục. Anchor text phải thuộc danh sách keyword landing page.

4. **Yêu cầu giải pháp**

Cập nhật prompt viết đoạn PR Vietnix: giới hạn 4-5 dòng, cấu trúc rõ ràng (PR tổng quan dịch vụ + link danh mục). Anchor text đi về trang danh mục phải thuộc danh sách keyword landing page đã có. Tham khảo format PR trên các bài viết mẫu.

5. **Acceptance Criteria**

|           |                      |
| --------- | -------------------- |
| **AC ID** | **Kết quả mong đợi** |
| AC-01     | Đoạn PR Vietnix ngắn gọn 4-5 dòng |
| AC-02     | Link đi về trang danh mục dịch vụ với anchor text thuộc keyword landing page |
