2. **User Story**

Là một **Content Writer**, Tôi muốn **heading PR Vietnix trong block "Những điểm chính" ghi theo format "Biết thêm Vietnix là..."**, Để **phần giới thiệu Vietnix tự nhiên và đúng chuẩn format**.
