# [Enhance] Outline ngắt đoạn xuống hàng block Vietnix

1. **Lịch sử thay đổi**

|             |                |                       |            |
| ----------- | -------------- | --------------------- | ---------- |
| **Version** | **Created by** | **Nội dung thay đổi** | **Ngày**   |
| v1.0        | BA Agent       | Tạo mới từ feedback   | 15.06.2026 |

2. **User Story**

Là một **Content Writer**, Tôi muốn **đoạn nội dung PR Vietnix trong outline được ngắt đoạn xuống hàng và đưa vào block Vietnix riêng**, Để **bài viết có cấu trúc rõ ràng, tách biệt phần PR và phần nội dung chính**.

3. **Mô tả vấn đề**

Trong outline, đoạn nội dung PR cho Vietnix đang nằm liền với nội dung chính, không ngắt đoạn xuống hàng. Theo feedback, đoạn này cơ bản phải ngắt đoạn xuống hàng, tốt hơn nữa là đưa vào block Vietnix riêng biệt để tách biệt với flow nội dung bài viết.

4. **Yêu cầu giải pháp**

Cập nhật cách tạo outline: khi có đoạn nội dung PR Vietnix, tự động ngắt đoạn và đưa vào block Vietnix riêng (custom block hoặc section riêng). Đảm bảo phần PR không bị trộn lẫn với nội dung heading chính.

5. **Acceptance Criteria**

|           |                      |
| --------- | -------------------- |
| **AC ID** | **Kết quả mong đợi** |
| AC-01     | Đoạn PR Vietnix được ngắt đoạn xuống hàng, nằm trong block Vietnix riêng biệt |
| AC-02     | Nội dung PR không bị trộn lẫn với nội dung heading chính |
