# [Bug] Block CTA chưa hoàn thiện thiếu vị trí sản phẩm

1. **Lịch sử thay đổi**

|             |                |                       |            |
| ----------- | -------------- | --------------------- | ---------- |
| **Version** | **Created by** | **Nội dung thay đổi** | **Ngày**   |
| v1.0        | BA Agent       | Tạo mới từ feedback   | 15.06.2026 |

2. **User Story**

Là một **Content Writer**, Tôi muốn **block CTA hoàn thiện với vị trí bổ sung sản phẩm chuyển đổi**, Để **bài viết có conversion point đúng chỗ**.

3. **Mô tả vấn đề**

Phần CTA (Call-to-Action) trong bài viết chưa hoàn thiện: chưa thấy vị trí bổ sung sản phẩm chuyển đổi. CTA hiện tại thiếu phần chuyển đổi về sản phẩm/dịch vụ cụ thể của Vietnix, khiến bài viết mất đi cơ hội conversion.

4. **Yêu cầu giải pháp**

Bổ sung vị trí sản phẩm chuyển đổi vào block CTA: cho phép chọn sản phẩm/dịch vụ Vietnix cụ thể (hosting, VPS, domain...) để đặt vào CTA. CTA phải có link và button chuyển đổi rõ ràng.

5. **Acceptance Criteria**

|           |                      |
| --------- | -------------------- |
| **AC ID** | **Kết quả mong đợi** |
| AC-01     | Block CTA có vị trí bổ sung sản phẩm chuyển đổi cụ thể |
| AC-02     | CTA có link và button chuyển đổi hoạt động đúng |
